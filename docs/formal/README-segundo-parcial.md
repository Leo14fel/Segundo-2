## Trabajo siguiente

1. Confirmar universidad, docente, grupo, fecha de entrega y formato o índice obligatorio. No completar estos datos por suposición.
2. Contrastar la consigna original del primer parcial y aprobar la numeración definitiva de CU-SP.
3. Revisar y completar los cinco casos de uso que aún no tienen especificación detallada.
4. Renderizar y revisar los diagramas; completar secuencia de resumen y propuesta de despliegue.
5. Configurar un proveedor real. El usuario dispone de Gemini, pero todavía no hay adaptador Gemini ni acceso API verificado.
6. Reunir evidencias con dos cuentas, voz, nube y teléfono real antes de marcar requisitos como aceptados.

Mantener la distinción entre implementación local, pruebas automatizadas, aceptación real y capacidades todavía propuestas. La creación de documentos en Drive no cambia sus permisos para compartirlos con el docente.
